----------------------------------------------------------------
HOW TO PUBLISH (GitHub Pages)
----------------------------------------------------------------
1. Go to your repo on github.com  ->  "Add file"  ->  "Upload files"
2. Drag in the CONTENTS of this folder (all 7 files + the
   assets folder + .nojekyll)  --  NOT the folder itself.
   ( If you drag the folder itself, the site ends up at
     yoursite.com/WEBSITE-UPLOAD/ instead of yoursite.com/ )
3. Commit.
4. Repo Settings -> Pages -> Source: "Deploy from a branch",
   Branch: main,  Folder: / (root).  Save.
5. Wait ~1 minute. Site is live.

If you use a drag-and-drop host (Netlify Drop, itch.io, etc.)
then you CAN just drop this whole folder in -- those hosts
treat the dropped folder as the site root.
